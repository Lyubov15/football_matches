# Матчи тура

Мобильное приложение **«Матчи тура»** на **Expo + React Native + TypeScript** для просмотра футбольных матчей тура.

Приложение загружает список матчей с сервера, отображает счёт, дату и время с учётом часового пояса устройства, позволяет фильтровать и искать команды, добавлять матчи в избранное и сохранять избранное между запусками приложения.

## Возможности

- загрузка матчей с сервера;
- отображение даты и времени в часовом поясе устройства;
- отображение текущего счёта и статуса матча на русском языке;
- состояние загрузки;
- обработка ошибки загрузки с кнопкой **«Повторить»**;
- отображение пустого списка;
- поиск матчей по названию команды;
- фильтрация матчей:
  - **все**;
  - **предстоящие**;
  - **завершённые**;
- ручное обновление списка матчей;
- отображение времени последнего обновления в формате **«обновлено N сек назад»**;
- добавление матчей в избранное;
- сохранение избранного в `AsyncStorage`;
- поддержка тёмной темы.

## Бонусы

В проекте реализованы дополнительные задания:

1. **Поиск по командам** — позволяет быстро найти матч по названию команды.
2. **Сохранение избранного** — избранные матчи сохраняются в `AsyncStorage` и не пропадают после перезапуска приложения.
3. **Тёмная тема** — интерфейс адаптируется под тёмное оформление устройства.

### Статусы матчей

Статус каждого матча отображается на русском языке в зависимости от его состояния.

Особая логика предусмотрена для отдельных типов матчей:

- `live` относится к фильтру **«Предстоящие»**;
- `postponed` отображается только в фильтре **«Все»**;
- для отложенного матча `startsAt` имеет значение `null`;
- для запланированных матчей, у которых ещё нет счёта, отображается **`- : -`**.

### Избранное

Избранные матчи сохраняются локально с использованием `AsyncStorage`.

Изменение списка избранного выполняется **иммутабельно**, без прямого изменения исходного массива или объекта состояния.

### Дата и время

Дата и время матча преобразуются и отображаются с учётом **часового пояса устройства пользователя**.

### Обновление данных

После загрузки матчей приложение фиксирует время последнего успешного обновления и показывает, сколько секунд прошло с момента обновления.

Кнопка **«Обновить»** позволяет вручную запросить актуальные данные.

## Требования

Для запуска проекта необходим:

- **Node.js 20+**
- **npm**

## Установка

Клонируйте репозиторий и установите зависимости:

```bash
git clone https://github.com/Lyubov15/football_matches.git
cd football_matches
npm install
```

## Запуск

### Web

```bash
npm run web
```

### Expo

```bash
npm start
```

### Android

```bash
npm run android
```

### iOS
