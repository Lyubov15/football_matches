# Матчи тура 
Мобильное приложение (Expo + React Native + TypeScript) для просмотра футбольных матчей тура.

## Возможности
- Загрузка списка матчей с сервера.
- Отображение счёта, даты и времени (в часовом поясе устройства), а также статуса на русском языке.
- Состояния загрузки, ошибки (с кнопкой «повторить») и пустого списка.
- Фильтрация по статусу: все / предстоящие / завершённые.
- Кнопка «Обновить» и таймер «обновлено N сек назад».
- Добавление матчей в избранное (звёздочка).
- Поиск по названию команды.
- Сохранение избранного между перезапусками (AsyncStorage).
- Тёмная тема.

## Бонусные задания
1. **Поиск по командам:** Мгновенная фильтрация списка по названию клуба.
2. **Сохранение избранного:** Звёздочки не сбрасываются при перезапуске благодаря `AsyncStorage`.
3. **Тёмная тема:** Стильный переключатель (Switch) для комфортного просмотра матчей ночью.

---

## Технологии
* **React Native** (через **Expo** для быстрого запуска на Web/iOS/Android)
* **TypeScript** (строгая типизация данных и пропсов)
* **AsyncStorage** (локальное сохранение избранного)
